# W&B LaTeX Source — DTD Ablation Study

This directory was generated from the report named [F-OAL | Thí nghiệm loại bỏ thành phần trên DTD](https://forge.coreweave.com/wandb/caoban170106-tr-ng-i-h-c-khoa-h-c-t-nhi-n-hqg-hcm/hcmus-foal-reproduction).

All charts are rendered as high resolution PNGs in the **charts** directory. The tables and metrics in this report were generated directly from the verified Colab GPU execution runs on the Describable Textures Dataset (DTD).

## Quickstart

You can upload this directory/zip into a new project at [Overleaf](https://www.overleaf.com/).
Choose "Upload Project" from the "New Project" menu to edit and compile online.

## Rendering Locally

Compile with: `pdflatex report.tex`
